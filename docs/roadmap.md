# Public roadmap

## 0.1 — Foundation

**Status: completed.**

Public-safe scope includes the local diagnostic engine, API/dashboard, CLI, safe cleanup, reversible Registry remediation, driver/firmware inventory, update discovery, reports and WinPE-oriented recovery tooling.

## 0.2 — Stabilization

**Status: next.**

The source roadmap includes Windows validation/correction, additional Registry coverage, correlation/history, stronger protection of local credentials, signed action receipts and dashboard improvements.

## 0.3 — Controlled repair

Planned analysis and repair workflows for Windows integrity, update cache, services/tasks, network reset and offline recovery.

## 0.4 — OEM adapters

Planned vendor-specific discovery, exact model matching, official package validation and recoverable vendor workflows.

## 0.5 — Remote management

Planned service hosting, mutual authentication, role-based authorization, support sessions, central history and remote writes only after sufficient audit maturity.

## 1.0 — Stable product

Reserved for multi-machine validation, recovery drills, threat-model review, signed packages, documented rollback and reproducible WinPE generation.

## Progress convention

The public percentage is an equal-weight count of named roadmap milestones only.

```text
completed milestones = 1
named milestones = 6
marker = 16.7%
```

It is not an effort estimate or production-readiness percentage.
